# Production Deployment Guide: NG Global Manpower Services

This guide provides step-by-step instructions for deploying the **NG Global Manpower Services** Node.js platform across **Render**, **VPS (Ubuntu + PM2 + Nginx)**, **Docker**, and **Cloud Platforms**.

---

## Pre-Deployment Checklist

1. Verify Node.js version is **v18+ LTS** (v24 LTS recommended).
2. Generate strong cryptographic keys for `JWT_SECRET` and `COOKIE_SECRET`:
   ```bash
   node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
   ```
3. Set `NODE_ENV=production` in your production environment.
4. Ensure the `./data` folder has write permissions for disk persistence.

---

## 1. Deploying to Render.com (Recommended Fast Cloud Setup)

Render provides zero-downtime continuous deployment directly from Git.

### Step 1: Create a Web Service
1. Log in to your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** &rarr; **Web Service**.
3. Connect your Git repository containing the NG Global codebase.

### Step 2: Configure Service Settings
- **Name:** `ng-global-manpower`
- **Environment:** `Node`
- **Region:** Choose the region closest to your primary candidate base (e.g., *Singapore / Frankfurt / Oregon*).
- **Branch:** `main`
- **Build Command:** `npm install`
- **Start Command:** `npm start`
- **Plan:** Free or Starter ($7/mo)

### Step 3: Add Persistent Disk (Critical for Data Preservation)
Because container filesystems are ephemeral on Render restarts:
1. In the service settings, scroll to **Disks**.
2. Click **Add Disk**.
3. **Name:** `ng-data`
4. **Mount Path:** `/opt/render/project/src/data`
5. **Size:** 1 GB (ample for hundreds of thousands of candidate records).

### Step 4: Add Environment Variables
Under the **Environment** tab, set:
```env
NODE_ENV=production
PORT=10000
APP_NAME="NG Global Manpower Services"
APP_URL=https://your-custom-domain.com
JWT_SECRET=your_super_secure_generated_jwt_secret
COOKIE_SECRET=your_super_secure_generated_cookie_secret
WHATSAPP_NUMBER=919876543210
HELPLINE_PHONE="+91 98765 43210"
SUPPORT_EMAIL=verification@ngglobalmanpower.com
DEFAULT_ADMIN_EMAIL=admin@yourdomain.com
DEFAULT_ADMIN_PASSWORD=YourStrongPasswordHere@2026
DEFAULT_ADMIN_NAME="Recruitment Director"
```
4. Click **Create Web Service**. Your platform will automatically build and deploy within 2 minutes.

## 2. Deploying to a Linux VPS (Ubuntu 22.04 / 24.04 LTS)

For maximum control, low latency, and full data sovereignty, deploy to an Ubuntu VPS (DigitalOcean, Hetzner, AWS EC2, or Linode) using PM2 process manager and Nginx as a reverse proxy.

### Step 1: Server Initialization & Node.js Setup
Connect via SSH to your VPS:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git ufw build-essential

# Install Node.js 24 LTS via NodeSource
curl -fsSL https://deb.nodesource.com/setup_24.x | sudo -E bash -
sudo apt install -y nodejs

# Verify versions
node -v
npm -v
```

### Step 2: Install PM2 Process Manager
```bash
sudo npm install -g pm2
```

### Step 3: Clone Codebase & Install Dependencies
```bash
sudo mkdir -p /var/www/ngglobal
sudo chown -R $USER:$USER /var/www/ngglobal

# Copy or clone files to /var/www/ngglobal
cd /var/www/ngglobal
git clone <your-git-repo-url> .

# Install dependencies (production only)
npm install --omit=dev

# Create data directory and set permissions
mkdir -p data
chmod 755 data
```

### Step 4: Configure Environment Variables
Create `/var/www/ngglobal/.env`:
```bash
nano /var/www/ngglobal/.env
```
Paste your production configuration:
```env
PORT=3000
NODE_ENV=production
APP_NAME="NG Global Manpower Services"
APP_URL=https://ngglobalmanpower.com
JWT_SECRET=use_a_64_character_hex_random_secret_here
COOKIE_SECRET=use_another_64_character_hex_random_secret
DB_FILE=./data/ngglobal.sqlite
WHATSAPP_NUMBER=919876543210
HELPLINE_PHONE="+91 98765 43210"
SUPPORT_EMAIL=verification@ngglobalmanpower.com
DEFAULT_ADMIN_EMAIL=admin@ngglobalmanpower.com
DEFAULT_ADMIN_PASSWORD=ChangeMeImmediately_2026!
DEFAULT_ADMIN_NAME="Recruitment Director"
```

### Step 5: Start with PM2 Process Manager
```bash
# Start the application cluster
pm2 start server.js --name "ng-global" -i max

# Save PM2 state and configure startup daemon
pm2 save
pm2 startup
```
*(Copy and run the `sudo env PATH=...` command generated by PM2 to enable auto-restart on system reboots).*

### Step 6: Configure Nginx Reverse Proxy with SSL
Install Nginx and Certbot:
```bash
sudo apt install -y nginx certbot python3-certbot-nginx
```

Create `/etc/nginx/sites-available/ngglobal`:
```bash
sudo nano /etc/nginx/sites-available/ngglobal
```
Paste the following configuration:
```nginx
server {
    listen 80;
    server_name ngglobalmanpower.com www.ngglobalmanpower.com;

    # Gzip Compression
    gzip on;
    gzip_vary on;
    gzip_min_length 1024;
    gzip_proxied expired no-cache no-store private auth;
    gzip_types text/plain text/css text/xml text/javascript application/javascript application/x-javascript application/json;
    gzip_disable "MSIE [1-6]\.";

    # Static assets caching
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2)$ {
        root /var/www/ngglobal/public;
        expires 7d;
        add_header Cache-Control "public, no-transform";
    }

    # Proxy to Node.js
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}
```

Enable site and restart Nginx:
```bash
sudo ln -s /etc/nginx/sites-available/ngglobal /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

Obtain free SSL certificate via Let's Encrypt:
```bash
sudo certbot --nginx -d ngglobalmanpower.com -d www.ngglobalmanpower.com
```

## 3. Containerized Deployment via Docker

### Dockerfile
Create a `Dockerfile` at the root of the project:
```dockerfile
FROM node:24-alpine AS base

WORKDIR /app

# Install dependencies
COPY package*.json ./
RUN npm ci --omit=dev

# Copy application files
COPY . .

# Ensure data directory exists
RUN mkdir -p /app/data && chown -R node:node /app

USER node

EXPOSE 3000

ENV NODE_ENV=production
ENV PORT=3000

CMD ["node", "server.js"]
```

### docker-compose.yml
```yaml
version: '3.8'

services:
  app:
    build: .
    container_name: ng_global_manpower
    restart: unless-stopped
    ports:
      - "3000:3000"
    volumes:
      - ./data:/app/data
    env_file:
      - .env
    environment:
      - NODE_ENV=production
      - PORT=3000
```

Run container:
```bash
docker compose up -d --build
```

## 4. Health Check & Verification

Once deployed, run these curl commands to verify service integrity:

```bash
# 1. Verify Public Homepage
curl -I https://your-domain.com/
# Expected: HTTP/2 200 OK

# 2. Verify Jobs Directory
curl -I https://your-domain.com/jobs
# Expected: HTTP/2 200 OK

# 3. Verify Public API
curl https://your-domain.com/api/v1/jobs
# Expected: {"success":true,"count":6,"jobs":[...]}

# 4. Verify Admin Portal Redirect
curl -I https://your-domain.com/admin/dashboard
# Expected: HTTP/2 302 Found (Location: /admin/login?redirect=...)
```

## 5. Backup & Maintenance

To back up your candidate leads and settings database:
```bash
# Backup candidate database
cp /var/www/ngglobal/data/ngglobal.json /var/www/ngglobal/data/backup_$(date +%F).json
```
Schedule daily automated backups via cron:
```bash
crontab -e
# Add line:
0 3 * * * cp /var/www/ngglobal/data/ngglobal.json /var/backups/ngglobal_$(date +\%F).json
```
