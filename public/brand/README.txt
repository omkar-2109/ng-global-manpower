# NG Global Manpower Services - Official Logo & Asset Pack

### Directory Structure:
1. **1_Favicons/**
   - `favicon.ico` (Multi-resolution 16/32/48px for browser tabs)
   - `favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`
   - `apple-touch-icon-180x180.png` (iOS Safari homescreen bookmark)
   - `android-chrome-192x192.png`, `android-chrome-512x512.png` (PWA / Mobile web)

2. **2_Web_Navbar_Logos/**
   - Standard navigation bar logos (1x, 2x Retina) with transparent backgrounds.
   - Horizontal wordmark version for compact desktop/mobile navigation headers.

3. **3_Social_Media_Profile_Icons/**
   - 1:1 Square aspect ratio profile pictures (400x400, 800x800, 1080x1080) for WhatsApp Business, LinkedIn, Facebook, and Instagram.
   - Dark mode versions (Deep Midnight Navy background #0A1128).

4. **4_Brand_Emblem_Only/**
   - High-definition standalone 3D emblem (Airplane, Globe, NG monogram) without text.

5. **5_Full_Corporate_Master/**
   - High-resolution corporate master files (1200px) including "Trusted Company" and "Registered Company" accreditation badges for letterheads, brochures, stamps, and footer.

6. **6_Transparent_PNGs/**
   - Clean transparent PNG formats ready to overlay onto light and dark website sections.

### Primary Color Codes:
- **Corporate Deep Navy:** `#0E2A47` / `#0A1128`
- **Prestige Warm Gold:** `#C79838` / `#D4AF37`
- **Background White:** `#FFFFFF`
